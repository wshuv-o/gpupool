Join the GPU pool

Add this machine's GPU to gpu.odinbd.com. About 5 minutes. Nothing is opened on your router or firewall: the machine dials out.

Before you start

  • An AI server already running on this machine, for example Ollama. Check it: open a terminal and run ollama list. You should see your models.
  • A setup key (starts with ek_). Ask whoever runs the pool for it. They find it on the dashboard at /_ui. Keep it private: anyone holding it can add a machine.

Quick way · Windows, one command

Open PowerShell and paste this, with your setup key and a name for this PC. It checks Node, Git and Ollama, installs the agent, joins the pool and keeps it running after reboots. If something is missing it stops and says exactly what to install.

$env:GPU_KEY='ek_...'; $env:GPU_LABEL='my-pc'; irm https://gpu.odinbd.com/install.ps1 | iex

Use a different GPU_LABEL on each PC. You can run it again at any time to repair or update.

The two options below do the same thing by hand, for other systems or if you prefer to see each step.

Option A · Windows program

1Download

Open PowerShell and run:

mkdir $env:USERPROFILE\gpupool -Force; cd $env:USERPROFILE\gpupool
Invoke-WebRequest https://github.com/wshuv-o/gpupool/releases/latest/download/gpupool.exe -OutFile gpupool.exe
Unblock-File .\gpupool.exe

The file is about 90 MB.

2Check it is the right version

.\gpupool.exe

The help text must list this line: gpupool setup leaf --key ...

If that line is missing, the download is an older version. Use Option B below instead.
If Windows says "An Application Control policy has blocked this file", that is Smart App Control. It cannot be allowed for one app. Do not turn it off (it can only be turned back on by reinstalling Windows). Use Option B instead.

3Join

Replace ek_... with your setup key and pick a name for this machine:

.\gpupool.exe setup leaf --key ek_... --root https://gpu.odinbd.com --label my-pc

It finds Ollama and your models by itself and connects. Use a different --label on each machine.

4Keep it running after reboots

.\gpupool.exe service install

This starts it each time you log in, with no admin rights needed. Add --system (from an Administrator PowerShell) to start it at boot before login.

5Check it worked

The machine should appear on the dashboard with a green dot and your model names. If you don't have the admin key, ask the pool owner to look.

Option B · From source (Windows, macOS, Linux)

Use this if Option A is blocked or out of date. You need Node.js 20 or newer and Git.

git clone https://github.com/wshuv-o/gpupool.git
cd gpupool
npm ci
npm run build
rm gpupool.yaml
node dist/agent/index.js setup leaf --key ek_... --root https://gpu.odinbd.com --label my-pc
node dist/agent/index.js service install
Don't skip rm gpupool.yaml (in PowerShell: Remove-Item gpupool.yaml). The download contains a sample file with that name, and setup leaves an existing file alone, so the machine would join under the wrong name and never receive requests. Setup writes a correct one for your machine.

On Windows, use node dist\agent\index.js if the slashes give you trouble. To update later: git pull, npm ci, npm run build.

"Too many failed attempts"Repeated wrong keys from your network. Wait 15 minutes.
